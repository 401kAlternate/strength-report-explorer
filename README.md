# Strength Report Explorer

Interactive Streamlit GUI for `strength-report-2026.csv`.

## Features
- Filter by dataset section, metric, and category
- KPI summary cards
- Interactive Plotly charts
- Custom chart builder
- Filtered data table
- CSV export
- Upload another compatible CSV

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy
Connect this repository to Streamlit Community Cloud and select `app.py`.
